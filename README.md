###### Trabalho da Faculdade QI -> Lista de Tarefas ######

## Sobre:
Este projeto é uma ferramenta simples para organizar suas tarefas diárias.

## Como Usar:
?

### Pré-Requisitos:
Não há pré-requisitos específicos para este projeto. Você só precisa de um navegador de internet para abrir o arquivo HTML.

### Execução:
1.  Baixe e descompacte o arquivo `Lista_Tarefas.zip`.
2.  Abra o arquivo `index.html` no seu navegador web preferido (Chrome, Firefox, Edge, etc.).

## Estrutura do Projeto:
* `index.html`: O arquivo principal da interface.
* `script.js`: Contém a lógica JavaScript para as funcionalidades.
* `style.css`: Define a aparência visual do projeto.
